Detailed Description

template<typename T, Mode::Lock M = Mode::Lock::Mutex>
struct AsyncFw::LockData< T, M >

A zero-copy RAII carrier that couples a synchronized resource view with its active lock guard.

The underlying mutex type and locking discipline are selected at compile time via the M template parameter: Mode::Lock::Mutex uses std::mutex with exclusive semantics, Mode::Lock::Exclusive uses std::shared_mutex::lock, and Mode::Lock::Shared uses std::shared_mutex::lock_shared. The lock is acquired in the constructor and released in the destructor, so the protected resource remains valid for the lifetime of the LockData instance.

Template Parameters
TThe resource type declaration, which must be either a reference or a pointer.
MThe locking discipline. Defaults to Mode::Lock::Mutex, which uses std::mutex with exclusive semantics.
