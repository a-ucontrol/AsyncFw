Detailed Description

template<typename T>
struct AsyncFw::LockData< T >

A zero-copy RAII carrier that couples a synchronized resource view with its active lock guard.

Enforces compile-time checks to ensure that the underlying type is strictly a reference or a pointer, effectively preventing accidental heavy memory allocations or copying during multi-threaded data sharing.

Template Parameters
TThe resource type declaration, which must be either a reference or a pointer.
