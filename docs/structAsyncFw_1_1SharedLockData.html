Detailed Description

template<typename T, Mode::Lock M = Mode::Lock::Exclusive>
struct AsyncFw::SharedLockData< T, M >

A zero-copy RAII carrier that couples a synchronized resource view with its active shared_mutex lock guard.

Enforces compile-time checks to ensure that the underlying type is strictly a reference or a pointer, effectively preventing accidental heavy memory allocations or copying during multi-threaded data sharing. The locking discipline is selected at compile time via the M template parameter.

Template Parameters
TThe resource type declaration, which must be either a reference or a pointer.
MThe locking discipline. Defaults to Mode::Lock::Exclusive, mirroring std::shared_mutex::lock.
