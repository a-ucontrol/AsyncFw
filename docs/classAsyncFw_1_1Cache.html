Detailed Description

template<typename T>
class AsyncFw::Cache< T >

thread-safe cache wrapper that automatically triggers an update signal when the value expires.

Implements the Stale-While-Revalidate pattern. When the cache expires, the first thread marks it as updating, temporarily releases the lock, and triggers an asynchronous update signal via a QueuedOnly policy. Subsequent readers during the update phase instantly receive the stale value without blocking, ensuring maximum high availability and zero downtime.
